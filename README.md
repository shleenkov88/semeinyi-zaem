# Семейный заём

Единственная рабочая версия кабинета договора займа № 1.
Превью на grok.me (`ivory-reef-orchid-ever.grok.me`) больше не используем — это устаревший снимок до первого платежа.

Открывается без VPN:

https://shleenkov88.github.io/semeinyi-zaem/

Статика: HTML + JS, без сервера.
Данные: `payments.json` (платежи), `cbr.json` (ключевая ставка ЦБ, обновляется workflow `cbr.yml`).
